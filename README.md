# Robot Climbs !!

## About the game

A top-down pixel art game about a robot dog delivering its cargo to the peaks of the mountain.

Deliver **10 times in total** to win. If you arrive short, the shopkeeper sends you back to the start to get more.

On the way up:
- **Rough ground** shakes your basket and loss an item when not holding shift.
- **Rolling rocks** come down from above, hit one and break one.
- **Boulders** go into one in high speed then an item breaks.

## Why I made it

I made this because in China there are robot dogs introduced to bring and give cargo items to reduce labor work.

## Controls

| Action | Key |
|---|---|
| Move | WASD / Arrow keys |
| Walk carefully | Hold Shift |
| Climb again (after a climb) | R |
| Back to menu (after a climb) | Esc |
